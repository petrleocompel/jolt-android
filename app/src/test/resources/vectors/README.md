# Relay test vectors

`envelope-v1.json` and `server-id.json` are copies of the normative vectors in
jolt-relay `spec/vectors/` (commit `fb9c1b7`, unchanged as of `eb16aae`), with
one added `_source` key saying so. The relay repository's `spec/protocol-v1.md` is the contract; when
it changes, copy the vectors again rather than editing them here.
